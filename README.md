## `03 // RESEARCH` 🔬

### 🧠 Replay-Augmented Regularisation for Class-Incremental Network Intrusion Detection

Co-authored with **Muhammad Iqbal Hossain** · 📄 [Read the paper on arXiv](https://arxiv.org/abs/2611.20498)

This study evaluates a **1D CNN** for class-incremental intrusion detection across **nine sequential attack-category tasks**, using the **UNSW-NB15, ToN-IoT, and CIC-IDS2017** datasets. It compares fine-tuning against replay-augmented **Elastic Weight Consolidation (EWC)** and **Learning without Forgetting (LwF)**.

```text
🧪 Model     : 1D CNN
📊 Datasets  : UNSW-NB15 · ToN-IoT · CIC-IDS2017
🎯 Tasks     : 9 sequential attack-category tasks
⚔️ Methods   : Fine-tuning vs. Replay + EWC vs. Replay + LwF
```

> 📌 **Status:** arXiv v1 preprint, submitted November 16, 2026. This is a preprint and has **not been peer reviewed**.

> ⚠️ **Limitations:** Results use a single seed, and the fine-tuning baseline did not use replay. The findings therefore do not establish that EWC or LwF provides benefits beyond replay alone.
